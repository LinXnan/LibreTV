# 2026-08-02 移动端历史面板横向溢出 Issue Report

## 1. 问题现象

移动端历史记录页面，打开历史面板后向左滑动卡片区域，会出现一大片空白区域。内容被拖出视口，面板右侧/整体出现空白，没有实际卡片内容。空白是橡皮筋效果般的横向回弹，并非内容丢失，松手时弹回。

## 2. 复现步骤

1. 手机浏览器访问 LibreTV 首页。
2. 点击历史记录按钮，打开历史面板。
3. 在历史面板内向左滑动卡片区域。
4. 观察到面板内容出现横向大片空白。

复现频率：稳定，每次都能复现。

## 3. 期望 vs 实际

**期望行为**：向左滑动历史卡片时内容应始终保持在视口内，只能垂直滚动，左右不会出现空白。

**实际行为**：向左滑动时内容被拖出视口，右侧出现大面积空白，面板内容横向错位。

## 4. 环境信息

- 涉及模块：历史记录面板（UI 组件，移动端抽屉式布局）
- 相关文件：css/styles.css (#historyList 移动端规则), js/ui.js (面板操作), js/mobile-panel-gestures.js (弹框/面板切换)
- 运行环境：手机浏览器，dev 环境。主流 iOS/Android 均可复现。
- 其他上下文：无数据库，所有状态都在 localStorage。

## 5. 严重程度

**P2 中等** — 非核心功能，影响部分用户，在计划内修复。
