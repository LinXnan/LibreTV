# 继续观看弹窗开关无法点击 Issue Report

## 1. 问题现象

首页设置面板中「继续观看弹窗」开关（toggle）点击后没有任何视觉变化：圆点不滑动、背景不变色，表现为"点了没反应/无法点击"。同一设置面板中的「分片广告过滤」「黄色内容过滤」开关点击后圆点会正常滑动并高亮。

## 2. 复现步骤

1. 打开首页（`index.html`）
2. 点击齿轮打开设置面板
3. 向下找到「继续观看弹窗」开关（位于「豆瓣热门推荐」下方）
4. 点击该开关
5. 观察到：开关视觉完全无变化；对比点击同面板「分片广告过滤」开关可正常切换（圆点滑动 + 高亮）

复现频率：稳定

## 3. 期望 vs 实际

**期望行为**：点击「继续观看弹窗」开关后，圆点右移、背景高亮（与其他开关一致的视觉反馈），且切换状态被持久化。

**实际行为**：点击后视觉完全无变化，用户感知为开关无法点击。

## 4. 环境信息

- 涉及模块 / 功能：首页设置面板（设置项开关）
- 相关文件 / 函数：`index.html:268-272`（开关 HTML 结构）、`css/styles.css:368-410`（开关 `:checked` 样式区）、`js/app.js:86-89`（初始化）、`js/app.js:710-715`（change 事件）
- 运行环境：dev（本地 Express）

## 5. 严重程度

**P2** — 非核心功能（设置项），但开关视觉失效直接影响该功能可用性的感知，且同类开关正常，属明显回归性 UI 缺陷。
