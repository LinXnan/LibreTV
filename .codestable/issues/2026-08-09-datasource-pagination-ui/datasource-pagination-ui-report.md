# 数据源面板分页文案与翻页跳动 Issue Report

## 1. 问题现象

设置面板的数据源（API 选择）区域分页控件存在两个问题：

1. 分页信息行显示"第 X/Y 页 · 每页 12 个"，多出"每页 N 个"字眼。
2. PC 端点击"下一页"按钮后，整个设置面板会平滑滚动跳到 API 列表顶部，造成面板内容向上跳动。

## 2. 复现步骤

1. 打开首页，点击设置按钮打开设置面板。
2. 向下滚动到数据源（API 选择）区域，查看分页控件。
   - 观察到：信息行显示"第 X/Y 页 · 每页 12 个"。
3. PC 端（窗口宽度 > 640px），滚动面板让"下一页"按钮可见，点击"下一页"。
   - 观察到：面板自动平滑滚动到 API 列表顶部，内容向上跳动。

复现频率：稳定。

## 3. 期望 vs 实际

**期望行为**：分页信息只显示"第 X/Y 页"，不出现"每页 N 个"字眼；PC 端点击下一页后，面板保持原滚动位置，不发生跳动。

**实际行为**：信息行多出"每页 12 个"；PC 端点击下一页后，面板自动平滑滚动到 API 列表顶部。

## 4. 环境信息

- 涉及模块 / 功能：设置面板 → 数据源（API 选择）区域分页控件
- 相关文件 / 函数：js/app.js 的 buildPagination()（约 115-147 行）、changeApiPage()（约 150-160 行）
- 运行环境：dev / prod 均可复现（无构建，刷新即生效）
- 其他上下文：数据源分页功能由提交 9f93c44 引入；分页按钮点击处已做 stopPropagation 防冒泡

## 5. 严重程度

**P3** — UI 文案冗余与交互轻微跳动，不影响数据源选择功能本身，属体验瑕疵。
