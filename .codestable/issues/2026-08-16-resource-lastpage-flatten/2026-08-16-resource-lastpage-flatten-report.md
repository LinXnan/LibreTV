# 2026-08-16 视频源面板最后一页卡片被纵向拉高 Issue Report

## 1. 问题现象

播放页右侧栏"视频源"面板，当搜索到的视频源总数超过一页（每页 6 个）时，翻到最后一页（如 3/3）若该页不足 6 个卡片（如只有 3 个），卡片会被纵向拉得很高，几乎占满整个模块高度，下方留下大段空白。

## 2. 复现步骤

1. 首页搜索一部多个视频源站点都能搜到的剧。
2. 点进播放页，右侧栏切到"视频源"Tab。
3. 视频源总数超过 6 个时翻到最后一页（如 3/3）。
4. 观察到：最后一页只有 3 张卡片，但卡片被纵向拉高，下方留大段空白。

复现频率：稳定复现。

## 3. 期望 vs 实际

**期望行为**：每一页都严格按照两行的高度布局——即使最后一页不足 6 个，卡片行高也应与满页时一致，多余的格子留空，不拉伸卡片。

**实际行为**：最后一页不足 6 个卡片时，卡片被拉到占满整个模块高度，下方留大段空白。

## 4. 环境信息

- 涉及模块 / 功能：播放页右侧栏"视频源"面板（resource-switch-list 网格）
- 相关文件 / 函数：js/player.js（renderResourcePage / RESOURCE_PAGE_SIZE=6）、css/player.css（.resource-switch-list）
- 运行环境：本地 dev（npm run dev）
- 其他上下文：无相关改动

## 5. 严重程度

**P2 中等** — 用户指定。视频源面板最后一页视觉异常，不影响播放与切源功能，但观感较差且出现在多视频源作品的常见操作路径上。
