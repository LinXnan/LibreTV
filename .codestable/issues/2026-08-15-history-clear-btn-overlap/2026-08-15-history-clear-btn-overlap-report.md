# 2026-08-15 清空历史记录按钮与历史记录重叠 Issue Report

## 1. 问题现象

历史记录面板中，"清空历史记录"按钮与历史记录列表内容发生重叠。列表滚动时按钮悬浮盖在记录卡片上方，遮挡内容。

## 2. 复现步骤

1. 打开首页历史记录面板。
2. 面板内有较多历史记录时，滚动查看列表。
3. 观察到：底部"清空历史记录"按钮与列表内容重叠，按钮盖住卡片。

复现频率：待确认（代码路径上桌面端为面板整体滚动 + sticky 按钮，重叠稳定可见；移动端待确认）。

## 3. 期望 vs 实际

**期望行为**：清空历史记录按钮固定在面板底部，历史记录在按钮上方独立滚动，两者不重叠。

**实际行为**：按钮悬浮在列表之上，滚动时覆盖在历史记录卡片上。

## 4. 环境信息

- 涉及模块：历史记录面板（UI 组件）
- 相关文件：index.html（清空按钮 DOM，约 144-148 行）、css/styles.css（.history-panel / #historyList 布局规则）
- 运行环境：dev，待确认桌面端 / 移动端
- 其他上下文：无

## 5. 严重程度

**P3 轻微** — UI 布局瑕疵，按钮与列表重叠影响观感与点击，非核心功能失效。具体定级待用户确认。
