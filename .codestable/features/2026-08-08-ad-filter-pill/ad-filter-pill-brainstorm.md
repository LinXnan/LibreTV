# 广告过滤统计胶囊化 Brainstorm

> Stage 0 | 2026-08-08 | 下一步：cs-feat（由主入口选择 lane）

## 想做什么、为什么

播放页 `player.html` 当前在播放器下方常驻一整行广告过滤统计条（`#adFilterStats`），文案"检测到视频存在 N 个广告,已为您过滤掉"，数字随播放实时累加。

痛点：常驻横条占位且抢注意力——即使只过滤 0/1 个广告也整行挂在播放器下方；加载时先显示"检测到 0 个广告"文案时机怪异；数字 scale-125 跳动反馈生硬。

目标：把统计改为轻量胶囊显示，保留计数能力与开关联动，不打扰观看。

## 考虑过的方向

### 方向 A：轻量胶囊化

- 描述：删除常驻横条，改为播放器角落紧凑胶囊（盾牌图标 + 数字），有广告被过滤时数字跳动反馈
- 价值：视觉干净、不占行、保留实时计数
- 代价：需处理胶囊定位与移动端遮挡
- 结论：**选定**

### 方向 B：浮出提示 + 自动消失

- 描述：过滤发生时右下角浮 toast，几秒淡出
- 结论：否决——实时累计反馈弱

### 方向 C：播放结束总结

- 描述：过程中不显示，暂停/结束时提示累计数
- 结论：否决——实时感最弱

### 方向 D：信息透明化面板

- 描述：可点击展开广告分段位置、片源含广告情况 + 播放页快捷开关
- 结论：否决（本轮不做，范围控制；"点击展开详情 + 快捷开关"记入遗留，可后续单独 feature）

## 已敲定的设计点

- 复用现有计数逻辑：`filterAdsFromM3U8` 统计、`totalAdsFiltered`、`updateAdFilterDisplay` 动画，不触碰过滤算法（已确认）
- 胶囊隐藏判定沿用 `updateAdFilterStatsVisibility`（广告过滤开关关闭时隐藏）（已确认）
- 改动面：`player.html` 容器结构一处 + `js/player.js` 两处函数微调（已确认）

## 选定方向与遗留问题

播放页广告过滤统计改为轻量胶囊：盾牌图标 + 过滤数字，贴在播放器区域角落，保留计数动画与开关联动。

核心行为：胶囊常驻但极小、数字跳动反馈、开关关闭即隐藏。
明显不做：toast / 结束总结 / 可展开信息面板（遗留）。
最大未知（留给 design）：
- 胶囊位置：播放器内部角落会被 ArtPlayer 控件层覆盖，更稳妥是紧贴播放器容器外右上角或与资源信息栏同排
- 移动端尺寸与遮挡处理
- 遗留：点击展开过滤详情 + 播放页快捷开关（未来可独立 feature）
