# Requirement: TMDB 热播轮播

## 用户故事

作为首页访客，我希望热播轮播的数据源从豆瓣（仅支持类型/标签筛选、不支持年份）替换为 TMDB，从而获得年份等更多筛选维度，同时保持"点击卡片 → 搜索播放"的现有体验。

## 核心行为

- 首页热播轮播数据源为 TMDB（discover 接口），支持电影/电视剧切换、标签筛选、年份筛选、换一批
- 卡片展示原片名、TMDB 评分（10 分制）、海报
- 点击卡片沿用现有"填充搜索框 → 采集站搜索"链路

## 成功标准

- 首页不再请求 `movie.douban.com`
- 年份筛选真实生效（discover 带 `primary_release_year`/`first_air_date_year`）
- 电影/电视剧/标签/年份/换一批五维切换全部走现有缓存与竞态保护

## 边界

- TMDB API key 前端配置（免费 key，暴露风险用户已接受）
- 不做 TMDB 登录态、不做播放直链
- 标签语义映射（如"冷门佳片"）退化为热门，不阻塞
