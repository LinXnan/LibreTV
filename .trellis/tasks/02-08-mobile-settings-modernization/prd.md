# 移动端设置页面现代化改进

## Goal
将移动端设置页面升级为符合 2026 年设计趋势的现代化界面，采用玻璃拟态 2.0 + Bento Grid 设计，优化触控体验和视觉层次。

## Requirements

### 视觉设计升级
- [ ] 实现沉浸式玻璃拟态效果（backdrop-filter blur + 半透明背景）
- [ ] 采用 Bento Grid 布局（大圆角卡片，独立背景）
- [ ] 升级面板圆角从 20px 到 32px
- [ ] 优化背景色为更深邃的 `rgba(15, 15, 18, 0.85)`
- [ ] 使用极细发光边缘 `rgba(255, 255, 255, 0.08)` 替代青色边框
- [ ] 去除硬质分割线，使用背景深浅变化区分层级

### 交互体验优化
- [ ] 实现弹性动效（cubic-bezier(0.32, 0.72, 0, 1)）
- [ ] 增强开关控件尺寸（52x28px）和发光效果
- [ ] 添加点击反馈动画（scale(0.97)）
- [ ] 优化按钮触控区域（高度 50px，圆角 16px）

### 布局优化
- [ ] 增加卡片间距到 16px
- [ ] 设置区域圆角升级到 24px
- [ ] 优化内边距和外边距
- [ ] 确保拖拽指示器样式现代化

### 保持兼容性
- [ ] 保留现有的赛博朋克风格核心元素（青色强调色）
- [ ] 不影响桌面端样式
- [ ] 保持现有的手势交互功能
- [ ] 确保无障碍访问性

## Acceptance Criteria

- [ ] 移动端设置面板呈现玻璃拟态效果
- [ ] 所有设置区域采用 Bento 卡片样式
- [ ] 面板打开/关闭动画流畅且有弹性
- [ ] 开关控件更大且有发光效果
- [ ] 按钮点击有明显的缩放反馈
- [ ] 视觉层次清晰，无硬质分割线
- [ ] 在不同尺寸的移动设备上测试通过
- [ ] 桌面端样式不受影响
- [ ] 代码符合前端质量规范

## Technical Notes

### 主要修改文件
- `css/mobile-optimize.css` - 移动端样式主文件
- 可能需要微调 `index.html` 中的 class 名称（如果需要）

### 设计参考（来自 Gemini）
- 玻璃拟态：`backdrop-filter: blur(25px) saturate(180%)`
- Bento 卡片：`border-radius: 24px`, `background: rgba(255, 255, 255, 0.04)`
- 弹性动画：`transition: transform 0.45s cubic-bezier(0.32, 0.72, 0, 1)`
- 开关发光：`box-shadow: 0 0 12px rgba(0, 242, 255, 0.4)`
