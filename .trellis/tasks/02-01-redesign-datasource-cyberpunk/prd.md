# 重新设计数据源设置区域（赛博朋克风格）

## Goal
将设置面板中的数据源设置区域重新设计为赛博朋克、现代、时尚的美学风格，提升视觉吸引力和用户体验。

## Requirements

### 视觉设计
- [ ] 霓虹边框效果（使用现有的 `--primary-color: #00ccff` 和 `--accent-color: #ff3c78`）
- [ ] 渐变背景（深蓝黑到深靛蓝）
- [ ] 发光效果（box-shadow 实现霓虹光晕）
- [ ] 扫光动画（卡片悬停时的光效，参考现有 `.video-card` 样式）
- [ ] 渐变文字标题（使用现有 `.gradient-text` 类）
- [ ] 选中状态的霓虹蓝发光效果

### 交互增强
- [ ] 悬停反馈：边框发光 + 轻微缩放/上移
- [ ] 选中动画：复选框选中时的脉冲效果
- [ ] 平滑过渡：所有状态变化使用 transition

### 响应式设计
- [ ] 桌面端：优化卡片布局和间距
- [ ] 移动端：保持 2 列网格，优化触摸体验
- [ ] 确保在不同屏幕尺寸下都有良好的视觉效果

## Acceptance Criteria

- [ ] 数据源设置区域具有明显的赛博朋克风格
- [ ] 霓虹边框和发光效果在深色背景下清晰可见
- [ ] 悬停和选中状态有流畅的动画反馈
- [ ] 桌面端和移动端都有良好的视觉效果
- [ ] 不影响现有功能（全选、全不选、API 选择等）
- [ ] 代码遵循项目的前端开发规范
- [ ] 无 XSS 漏洞，无运行时错误

## Technical Notes

### 需要修改的文件
1. **index.html** (第 165-195 行)
   - 数据源设置区域的 HTML 结构
   - 可能需要添加新的 CSS 类名

2. **css/styles.css**
   - 添加桌面端的赛博朋克样式
   - 霓虹边框、发光效果、悬停动画

3. **css/mobile-optimize.css** (第 1487-1627 行)
   - 优化移动端的 `.mobile-api-grid` 样式
   - 增强复选框的赛博朋克风格

4. **js/app.js** (第 103-237 行)
   - 可能需要调整 `initAPICheckboxes()` 中的 CSS 类名
   - 确保新样式与现有逻辑兼容

### 现有资源可复用
- 赛博朋克配色变量（`:root` 中已定义）
- `.gradient-text` 类（渐变文字效果）
- `.video-card` 的悬停动画（可参考扫光效果）
- 自定义复选框样式（已有基础样式）

### 设计原则
- 使用现有的配色系统，保持视觉一致性
- 不破坏现有功能和交互逻辑
- 遵循项目的纯 JavaScript + Tailwind CSS 架构
- 注重性能，避免过度使用动画导致卡顿
