# 重构选集弹框为横向Tab分组展示

## Goal

根据移动端操作习惯，将播放页面选集弹框从平铺网格改为横向Tab分组展示，提升大量集数时的浏览体验。

## Requirements

1. **横向Tab分组**
   - 顶部显示集数范围Tab (如: 1-20 | 21-40 | 41-60)
   - Tab支持横向滑动（当分组较多时）
   - 点击Tab切换显示对应范围的集数
   - 当前播放集数所在分组默认选中

2. **分组规则**
   - 每组固定20集
   - 最后一组可能不足20集
   - 示例: 总共65集 → 1-20 | 21-40 | 41-60 | 61-65

3. **集数展示**
   - 保持现有4列网格布局
   - 保持当前集数高亮样式
   - 保持自动滚动到当前集数功能

4. **兼容性**
   - 移动端和桌面端都需要支持Tab分组
   - 保持现有的手势关闭功能
   - 保持自动连播开关和排序功能

## Acceptance Criteria

- [ ] Tab分组正确显示，每组20集
- [ ] 点击Tab切换内容正常
- [ ] 当前播放集数所在Tab默认选中
- [ ] 当前播放集数在内容区高亮显示
- [ ] Tab较多时支持横向滑动
- [ ] 移动端手势关闭功能正常
- [ ] 桌面端显示正常
- [ ] 排序功能正常（正序/倒序）
