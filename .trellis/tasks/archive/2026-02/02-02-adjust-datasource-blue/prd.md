# Feature: 调整数据源设置蓝色亮度

## Requirements

### Background
用户反馈设置面板中数据源设置区域的蓝色过于明亮，需要调暗以提升视觉舒适度，同时保持美观性。

### Scope
- **仅调整数据源设置区域**的蓝色，不影响其他区域
- 调整范围：中度调暗（降低20-30%亮度）
- 需要考虑移动端和PC端的显示效果

### Target Elements
需要调整以下元素的蓝色：

1. **数据源容器** (`.datasource-section`)
   - 边框颜色
   - 悬停效果
   - 扫光动画

2. **API选择项** (`.datasource-section .grid.grid-cols-2 > .flex.items-center`)
   - 默认状态背景和边框
   - 悬停状态
   - **选中状态**（重点调整）

3. **复选框** (`.datasource-section .form-checkbox`)
   - 边框颜色
   - **选中状态背景和阴影**（重点调整）

4. **其他元素**
   - 标题文字阴影
   - 批量操作按钮悬停效果
   - 滚动区域边框
   - 信息显示区域

### Color Adjustment Strategy

**当前颜色**：`#00ccff` (RGB: 0, 204, 255)
- HSL: 187°, 100%, 50%

**目标颜色**（降低25%亮度）：
- 方案1: 降低亮度 → HSL: 187°, 100%, 37.5% → `#009fbf` (RGB: 0, 159, 191)
- 方案2: 降低饱和度+亮度 → HSL: 187°, 80%, 40% → `#1a99b3` (RGB: 26, 153, 179)

**推荐使用方案1**：保持饱和度，仅降低亮度，维持科技感。

### Implementation Details

#### 需要修改的文件
- `css/styles.css` (行 1233-1495)

#### 调整方法
1. **不修改全局变量** `--primary-color`，避免影响其他区域
2. **针对数据源设置区域**，使用更暗的蓝色值替换
3. **保持透明度比例**，确保层次感

#### 具体调整
将所有 `rgba(0, 204, 255, x)` 替换为 `rgba(0, 159, 191, x)`：
- 边框：`rgba(0, 159, 191, 0.2)` ~ `rgba(0, 159, 191, 0.4)`
- 背景：`rgba(0, 159, 191, 0.03)` ~ `rgba(0, 159, 191, 0.15)`
- 阴影：`rgba(0, 159, 191, 0.1)` ~ `rgba(0, 159, 191, 0.5)`

将 `var(--primary-color)` 在数据源区域替换为 `#009fbf`

## Test Plan

### Manual Testing
1. **桌面端测试**
   - 打开设置面板，查看数据源设置区域
   - 验证默认状态的蓝色亮度是否降低
   - 悬停在API选项上，验证悬停效果
   - 选中/取消选中API，验证选中状态的蓝色亮度
   - 验证复选框的选中状态颜色

2. **移动端测试**
   - 在移动设备或浏览器开发者工具的移动模式下测试
   - 验证所有状态的颜色显示效果

3. **对比测试**
   - 对比其他区域的蓝色（如搜索框），确认未受影响
   - 对比调整前后的视觉效果，确认改进

### Visual Inspection
- [ ] 蓝色亮度适中，不会过亮刺眼
- [ ] 保持科技感和赛博朋克风格
- [ ] 选中状态清晰可辨

## Notes

- 调整后的颜色值 `#009fbf` 可以作为"柔和蓝"的参考值
