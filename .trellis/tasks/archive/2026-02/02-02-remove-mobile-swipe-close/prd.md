# Feature: 移除移动端面板下滑关闭手势

## 需求描述

移除移动端三个面板的下滑关闭手势功能：
1. 历史记录面板
2. 设置面板
3. 选集面板

用户反馈下滑关闭手势容易误触，影响使用体验。移除后，用户只能通过点击遮罩层或返回键来关闭面板。

## 技术实现

### 涉及文件

**核心文件**:
- `js/mobile-panel-gestures.js` - 手势处理核心逻辑（362行）

**相关文件**:
- `index.html` - 历史记录和设置面板的 HTML 结构
- `player.html` - 选集面板的 HTML 结构
- `js/ui.js` - 历史记录和设置面板的业务逻辑
- `js/player.js` - 选集面板的业务逻辑
- `css/mobile-optimize.css` - 移动端样式

### 需要移除的功能

1. **触摸事件监听器** (`js/mobile-panel-gestures.js`):
   - `touchstart` 事件处理
   - `touchmove` 事件处理
   - `touchend` 事件处理

2. **手势识别逻辑**:
   - `handleTouchStart()` 函数
   - `handleTouchMove()` 函数
   - `handleTouchEnd()` 函数
   - `setupPanelGestures()` 函数

3. **拖拽相关状态**:
   - `isDragging` 状态
   - `startY`, `currentY` 位置记录
   - `velocityTracker` 速度追踪

### 需要保留的功能

1. **面板打开/关闭管理**:
   - `openPanel()` 函数
   - `closePanel()` 函数

2. **遮罩层点击关闭**:
   - `handleOverlayClick()` 函数
   - 遮罩层点击事件监听

3. **返回键支持**:
   - `handleBackButton()` 函数
   - 返回键事件监听

4. **焦点管理**:
   - `trapFocus()` 函数
   - 焦点陷阱逻辑
