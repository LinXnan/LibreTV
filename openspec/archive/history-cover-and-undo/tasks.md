// 验证URL协议是否安全（仅允许http/https）
function isValidImageUrl(url) {
    if (!url || typeof url !== 'string') return false;
    try {
        const parsed = new URL(url);
        return ['http:', 'https:'].includes(parsed.protocol);
    } catch (e) {
        return false;
    }
}

## 安全修复记录

### 修复 1: PC端 XSS 风险消除

**问题**: `onclick="playFromHistory('${item.url}', ...)"` 直接注入 URL

**修复**: 改用索引方式
```javascript
// 修复前
onclick="playFromHistory('${item.url}', '${safeTitle}', ...)"

// 修复后
data-index="${index}" onclick="playFromHistoryByIndex(${index})"
```

**影响**: 消除 localStorage 篡改导致的 XSS 风险

### 修复 2: 空值防护

**问题**: `item.title.replace()` 可能在空值时崩溃

**修复**: 添加默认值
```javascript
// 修复前
const safeTitle = item.title.replace(...)

// 修复后
const safeTitle = (item.title || '未知视频').replace(...)
```

**影响**: 提高鲁棒性，防止渲染崩溃
