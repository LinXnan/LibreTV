# 移动端数据源设置卡片重构 - 规范文档

## 变更 ID
`mobile-datasource-card-redesign`

## 需求概述

针对移动端主流操作习惯，重构设置面板中的数据源设置卡片，提升移动端用户体验的人性化程度。

---

## 功能需求

### FR-1: 卡片化设计
**描述**：将 API 列表从复选框列表改为卡片式布局。

**验收标准**：
- 每个 API 源显示为独立卡片
- 卡片间距：8px 垂直间距
- 卡片内边距：12px
- 卡片圆角：12px
- 卡片背景：`bg-[#151515]`
- 卡片边框：`border-[#2a2a2a]` 1px
- 选中状态边框：`border-[#3b82f6]`

### FR-2: 触摸目标优化
**描述**：所有交互元素符合移动端触摸目标标准。

**验收标准**：
- 所有可点击元素触摸区域 ≥44x44px
- 卡片最小高度：44px
- 操作栏按钮：≥44x44px，间距 ≥8px
- 整个卡片行可点击以切换选择

### FR-3: 滑动删除手势
**描述**：自定义 API 支持向左滑动删除。

**验收标准**：
- 仅支持左滑显示操作，右滑关闭
- 激活阈值：水平移动 ≥24px 且 |dx| ≥ 2*|dy|
- 完成删除阈值：滑动距离 ≥40% 卡片宽度 OR 速度 ≥0.6px/ms
- 操作区域宽度：移动端 72px，桌面端 88px
- 动画时长：打开/关闭 180ms ease-out，回弹 120ms ease-in
- 同时最多一个卡片处于打开状态
- 删除后显示 5 秒撤销提示（无确认对话框）
- 顶部 60px 区域禁用滑动（避免与面板拖动冲突）

### FR-4: 底部操作栏
**描述**：批量操作按钮移至底部固定栏。

**验收标准**：
- 位置：`position: sticky; bottom: 0;`
- 最小高度：56px
- 包含三个操作：全选、全不选、选择普通资源
- 按钮间距：≥8px
- 底部内边距：12px + `env(safe-area-inset-bottom)`
- 列表容器底部内边距：≥64px（避免遮挡）
- 无 API 时禁用（opacity 0.5, pointer-events none）

### FR-5: 响应式设计
**描述**：移动端优化仅在小屏幕生效，桌面端保持原有布局。

**验收标准**：
- 响应式断点：640px（Tailwind `sm`）
- ≤640px：应用卡片布局、滑动手势、底部操作栏
- >640px：保持原有网格布局、内联按钮、顶部操作按钮
- 桌面端禁用滑动手势

## 非功能需求

### NFR-1: 性能
- 设置面板打开动画 <400ms
- API 列表渲染时间 <100ms（50个API）
- 滑动操作响应延迟 <16ms（60fps）
- 内存占用增加 <1MB
- 使用 `requestAnimationFrame` 处理滑动变换
- 使用事件委托而非每个卡片独立监听器

### NFR-2: 可访问性
- 所有交互元素支持键盘导航（Tab 键）
- 使用语义化 HTML 标签
- 卡片使用 `role=group`，包含 API 名称标签
- 删除按钮使用 `aria-label='Delete custom API <name>'`
- 删除后焦点移至下一个卡片（无则移至添加按钮）
- 桌面端保持编辑/删除按钮可见

### NFR-3: 兼容性
- 使用 Pointer Events（可用时），回退到 Touch Events（iOS）
- 支持 `prefers-reduced-motion`
- 使用 CSS `transform` 而非 `position` 动画
- 保持 localStorage 数据结构不变

## 技术约束

### TC-1: 技术栈
- 必须使用 Tailwind CSS 框架
- 数据存储在 localStorage（`selectedAPIs`, `customAPIs`）
- 必须兼容现有 `API_SITES` 配置结构
- 必须与 `mobile-panel-gestures.js` 集成

### TC-2: DOM 结构
- 保留现有 ID：`#apiCheckboxes`, `#customApisList`, `#selectedApiCount`, `#addCustomApiForm`
- 保留复选框输入（可视觉隐藏但必须在 DOM 中）
- 保留 `.api-adult` 类名（用于成人内容过滤器联动）
- 不改变 `data-custom-index` 属性（用于删除/编辑）

### TC-3: JavaScript 逻辑
- 保持现有函数签名：`updateSelectedAPIs()`, `renderCustomAPIsList()`, `removeCustomApi()`
- 使用事件委托处理滑动和点击
- 选择切换时不重新渲染，仅在添加/编辑/删除时重新渲染
- 滑动任何卡片时关闭添加/编辑表单

### TC-4: 集成约束
- 配置管理操作**不需要**密码验证
- 选中成人 API 时必须禁用黄色过滤器并设置 `yellowFilterEnabled=false`
- 滑动手势不触发面板关闭（方向锁定）
- 面板拖动时立即取消滑动状态

## 基于属性的测试（PBT）不变量

### 幂等性

**PBT-1**: 重复调用 `selectAllAPIs(true)` 产生相同的 `selectedAPIs` 和复选框状态。
- **验证策略**：随机调用 2-5 次，断言第一次后状态不变。

**PBT-2**: 重复调用 `selectAllAPIs(false)` 清空内置 API 选择，保留自定义选择。
- **验证策略**：混合选择后多次调用，验证内置清空但自定义保留。

**PBT-3**: 重复打开/关闭滑动卡片不改变 localStorage。
- **验证策略**：同一卡片打开/关闭 3-10 次，验证 `customAPIs` 和 `selectedAPIs` 不变。

**PBT-4**: 重复渲染 `renderCustomAPIsList()` 产生相同 DOM。
- **验证策略**：无状态变更时渲染两次，对比序列化 DOM。

### 不变量保持

**PBT-5**: `selectedAPIs` 始终是 DOM 中已选中元素的并集。
- **验证策略**：随机切换和删除后，从 DOM 计算并集并与 localStorage 比较。

**PBT-6**: 每个 `custom_${index}` 指向有效的 `customAPIs[index]`。
- **验证策略**：随机删除后检查索引 <0 或 ≥length。

**PBT-7**: 删除索引 i 后，所有 i 之后的自定义选择索引减 1。
- **验证策略**：生成 N 个自定义 API，选择子集，删除索引 i，验证重新编号。

**PBT-8**: 选中任何成人 API 时，`yellowFilterEnabled` 必须为 false 且切换禁用。
- **验证策略**：选中成人 API 后断言 localStorage 和 UI 状态；取消选择后验证重新启用。

**PBT-9**: 5 秒内撤销恢复原始索引和选择状态。
- **验证策略**：删除前快照，5 秒内撤销，对比快照。

**PBT-10**: 桌面端（>640px）滑动手势不删除，按钮保持功能。
- **验证策略**：641px+ 视口下运行手势测试，断言无删除。

**PBT-11**: 配置更改不触发密码模态框。
- **验证策略**：启用密码保护后模拟配置更改，断言无模态框调用。

**PBT-12**: 同时最多一个滑动项打开。
- **验证策略**：打开卡片 A 后打开卡片 B，验证 A 关闭。

**PBT-13**: 重新渲染后滑动状态不持久化。
- **验证策略**：打开滑动，触发重新渲染，验证所有卡片关闭。

**PBT-14**: DOM 复选框数量 = `selectedAPIs.length` = `#selectedApiCount` 显示值。
- **验证策略**：随机操作后验证三者一致性。

### 边界

**PBT-15**: 滑动删除仅在阈值满足时触发。
- **验证策略**：生成低于阈值或 dy 主导的手势，断言无删除且卡片关闭。

**PBT-16**: 顶部 60px 区域忽略滑动。
- **验证策略**：模拟 y≤60px 和 y>60px 的滑动，断言仅后者可打开。

**PBT-17**: 触摸目标 ≥44x44px。
- **验证策略**：≤640px 视口下测量边界框，任何 <44px 失败。

**PBT-18**: 撤销窗口精确 5 秒，无确认对话框。
- **验证策略**：删除后观察无模态框，5 秒后撤销无效。

**PBT-19**: 操作栏不遮挡列表内容。
- **验证策略**：计算最后一项可见性和滚动位置，验证无遮挡。

### 交换性

**PBT-20**: 切换不同 API 的顺序不影响最终集合。
- **验证策略**：切换 A→B vs B→A，对比 `selectedAPIs` 集合。

**PBT-21**: 滑动卡片 X 后选择 Y 与选择 Y 后滑动 X 产生相同状态。
- **验证策略**：执行两种顺序，对比所有状态。

**PBT-22**: 全选普通资源后全不选与全不选后全选普通资源产生相同状态（自定义除外）。
- **验证策略**：对比两种顺序的最终集合。

### 往返

**PBT-23**: localStorage 序列化/反序列化重建相同数组。
- **验证策略**：随机生成，持久化，重新加载，深度对比。

**PBT-24**: 删除后 5 秒内撤销恢复原始 localStorage 值。
- **验证策略**：快照序列化值，删除并撤销，对比序列化值。

**PBT-25**: 编辑操作仅改变目标字段。
- **验证策略**：捕获选择和其他条目，编辑一个 API，验证仅目标字段变化。

### 单调性

**PBT-26**: 选择操作不减少 `selectedApiCount`（除非显式取消选择/删除）。
- **验证策略**：应用随机选择（无取消选择/删除），断言计数非递减。

**PBT-27**: 自定义 API 列表长度变化精确 ±1；撤销恢复长度。
- **验证策略**：跟踪添加/删除/撤销序列的长度变化。

### 手势方向排他性

**PBT-28**: 单次触摸不能同时触发卡片滑动和面板滚动/关闭。
- **验证策略**：模拟 deltaX=5px, deltaY=20px 的触摸路径，确保水平滑动为 false，垂直滚动/拖动关闭为 active。

### localStorage 原子一致性

**PBT-29**: 每次状态变更精确一次 `setItem` 调用。
- **验证策略**：模拟滑动删除后立即 `beforeunload` 事件，验证删除已持久化（即使撤销提示仍活动）。

## 边缘情况

### EC-1: 空列表
- 无自定义 API 时，滑动处理器无操作
- 保留空状态消息

### EC-2: 超长文本
- API 名称：1 行截断（`truncate`）
- URL：1 行截断
- 移动端无换行

### EC-3: 滚动冲突
- 仅在水平移动超过阈值后锁定滑动
- 否则允许正常滚动

### EC-4: 部分打开状态
- 点击部分打开的卡片：第一次点击关闭滑动，第二次切换选择

### EC-5: 成人 API 联动
- 选中成人 API 时立即禁用黄色过滤器
- 取消选择所有成人 API 后重新启用

### EC-6: 键盘遮挡
- 聚焦输入时滚动到视图
- 操作栏使用安全区域内边距和额外底部内边距

### EC-7: 空选择
- 批量操作后 `selectedAPIs` 为空时，搜索守卫保持不变
- 可选：操作栏附近显示本地警告

### EC-8: 编辑中删除
- 删除索引与编辑项匹配时，重置表单并恢复添加按钮

## 成功标准

### 可验证场景

#### 场景 1：触摸目标符合标准
**Given**: 用户在移动端打开设置面板
**When**: 查看数据源设置区域
**Then**:
- 所有可点击元素触摸区域 ≥44x44px
- Chrome DevTools 触摸模拟可轻松点击任何元素
- 不会误触相邻元素

#### 场景 2：卡片化设计清晰
**Given**: 用户在移动端查看 API 列表
**When**: 滚动浏览 API 源
**Then**:
- 每个 API 源显示为独立卡片
- 卡片间距 ≥8px
- 选中状态有明显视觉反馈（边框颜色变化）
- 卡片内信息层次清晰

#### 场景 3：滑动删除自定义 API
**Given**: 用户添加了自定义 API
**When**: 在自定义 API 卡片上向左滑动
**Then**:
- 显示删除按钮（红色背景）
- 点击删除后显示 5 秒撤销提示（无确认对话框）
- 5 秒内点击撤销恢复 API
- 5 秒后撤销按钮消失
- 支持向右滑动取消删除操作

#### 场景 4：底部操作栏易于操作
**Given**: 用户需要批量操作 API
**When**: 查看设置面板底部
**Then**:
- 批量操作按钮固定在底部（拇指易达区域）
- 按钮间距 ≥8px
- 按钮高度 ≥44px
- 按钮文字清晰可读（字号 ≥14px）
- 最后一项 API 完全可见（不被遮挡）

#### 场景 5：桌面端功能不受影响
**Given**: 用户在桌面端打开设置面板
**When**: 操作数据源设置
**Then**:
- 保持原有网格布局
- 保持原有复选框交互
- 保持原有批量操作按钮位置
- 滑动手势不触发删除
- 编辑/删除按钮保持可见和功能

#### 场景 6：手势冲突正确处理
**Given**: 用户在移动端滑动卡片
**When**: 手势方向不明确（对角线）
**Then**:
- 垂直移动主导时允许滚动，取消滑动
- 水平移动主导时锁定滑动，阻止滚动
- 顶部 60px 区域不触发滑动
